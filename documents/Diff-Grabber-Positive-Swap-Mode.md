## สรุปโหมด Positive Swap ของ Diff-Grabber (MT4/MT5)

เอกสารนี้สรุปพฤติกรรมฟีเจอร์ตามค่าเริ่มต้น (defaults) เมื่อสลับค่า `input_trading_positive_swap` ระหว่าง `true/false` สำหรับ `Diff-Grabber.mq4` และ `Diff-Grabber.mq5` โดยเวลาทั้งหมดอ้างอิงเวลาเครื่อง (TimeLocal) ของเทอร์มินัล

### เมื่อ `input_trading_positive_swap = false`

| ฟีเจอร์ | สถานะ | ช่วงเวลา/ค่า (ดีฟอลต์) |
|---|---|---|
| Scheduled Close-Only (รายวัน) | เปิดใช้งาน | 01:00–08:00 ทุกวัน (ปิดรับการเปิดออเดอร์ใหม่ แต่ให้ออเดอร์ที่เปิดอยู่ปิดได้) |
| Weekend Close-Only (เสาร์→จันทร์) | เปิดใช้งานเสมอ | เริ่ม เสาร์ 01:00 → ครอบคลุมทั้งวันอาทิตย์ → สิ้นสุด จันทร์ 08:00 |
| Close Threshold Schedule (ปรับ close_th ตามเวลา) | เปิดใช้งาน | ใช้ “เวลาล่าสุดที่ไม่เกินปัจจุบัน” ตามดีฟอลต์ด้านล่าง |
| • 01:00 | — | close_th = 20 |
| • 02:00 | — | close_th = 10 |
| • 03:00 | — | close_th = 0 |
| • 03:15 | — | close_th = 1000 |
| • 05:30 | — | close_th = 25 |
| Force Close at Time (ปิดทุกออเดอร์ตามเวลา) | เปิดใช้งาน | 03:15 ทุกวัน (ทำงานเฉพาะกรณีมีออเดอร์เปิดอยู่) |
| Saturday Quiet Window (เฉพาะวันเสาร์) | ใช้งานเสมอ | 03:25–08:00 (บล็อกการเปิด/ปิดอัตโนมัติบางส่วน เช่น reconcile, auto open/close) |

หมายเหตุ: แม้ `input_force_close_time_enabled` ดีฟอลต์เป็น `false` แต่เมื่อ `positive_swap = false` ระบบบังคับให้ฟีเจอร์ Force Close ทำงานทุกวัน (ยกเว้นถูกกันด้วย Quiet Window เมื่อเวลาทับซ้อน)

### เมื่อ `input_trading_positive_swap = true`

| ฟีเจอร์ | สถานะ | ช่วงเวลา/ค่า (ดีฟอลต์) |
|---|---|---|
| Scheduled Close-Only (รายวัน) | ปิดใช้งาน | — |
| Weekend Close-Only (เสาร์→จันทร์) | เปิดใช้งานเสมอ | เริ่ม เสาร์ 01:00 → ครอบคลุมทั้งวันอาทิตย์ → สิ้นสุด จันทร์ 08:00 |
| Close Threshold Schedule | ปิดใช้งาน | — |
| Positive Swap override (บังคับ close_th) | เปิดใช้งาน | 03:00–05:30 เฉพาะ วันจันทร์–ศุกร์ (ไม่นับวันเสาร์): close_th = 1000; นอกช่วงกลับไปใช้ close_th ปกติ (ดีฟอลต์ 25) |
| Force Close at Time | ปิดใช้งานปกติ | ยกเว้น "วันเสาร์" ยังบังคับทำงานเวลา 03:15 ถ้ามีออเดอร์เปิดอยู่ |
| Saturday Quiet Window (เฉพาะวันเสาร์) | ใช้งานเสมอ | 03:25–08:00 (บล็อกการเปิด/ปิดอัตโนมัติบางส่วน เช่น reconcile, auto open/close) |

หมายเหตุ: Force Close ในวันเสาร์จะยังทำงานเวลา 03:15 (ซึ่งอยู่ก่อนช่วง Quiet Window 03:25–08:00) จึงไม่ถูกบล็อกโดย Quiet Window ในวันเสาร์

### ค่าดีฟอลต์ที่เกี่ยวข้อง (จากโค้ด)

- Scheduled Close-Only (รายวัน): `01:00–08:00`
- Weekend Close-Only: `เสาร์ 01:00 → จันทร์ 08:00`
- Close Threshold Schedule (เมื่อโหมดนี้เปิดใช้งาน):
  - `01:00 → 20`, `02:00 → 10`, `03:00 → 0`, `03:15 → 1000`, `05:30 → 25`
- Positive Swap override window: `03:00–05:30` (วันจันทร์–ศุกร์เท่านั้น) ค่า `close_th = 1000`
- Force Close at Time: `03:15`
- Saturday Quiet Window: `03:25–08:00` (วันเสาร์)
- ค่า threshold พื้นฐาน: `open_th = 25`, `close_th = 25` (กลับมาใช้ค่านี้เมื่ออยู่นอกหน้าต่าง override/schedule)

### หมายเหตุเพิ่มเติม

- เวลาทั้งหมดอ้างอิง TimeLocal ของเทอร์มินัล
- ระบบมีการกันไม่ให้ Force Close แทรกแซงระหว่าง Quiet Window ของวันเสาร์ (แต่เวลา 03:15 อยู่ก่อน Quiet Window จึงยังทำงานได้)
- พฤติกรรมของ MT4 และ MT5 ในส่วนนี้เหมือนกันตามโค้ดปัจจุบัน
